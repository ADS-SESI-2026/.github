# ADS SESI 2026 — Organização GitHub

Bem-vindo(a) à organização **ADS SESI 2026** no GitHub!

## 🎯 Objetivo da Organização

Esta organização foi criada para apoiar o desenvolvimento de habilidades essenciais para o mercado de desenvolvimento de software, com foco em:

- **Versionamento de código** com Git e GitHub (branches, commits, tags e histórico de alterações)
- **Trabalho em equipe** por meio de repositórios compartilhados, revisão de código e colaboração assíncrona
- **Resolução de conflitos em Pull Requests**, praticando a integração de mudanças simultâneas de forma segura e organizada

Todos os projetos, atividades e avaliações práticas do curso serão realizados neste espaço.

---

## 🎓 GitHub Education

Esta organização faz parte do programa **[GitHub Education](https://education.github.com/)**, que oferece recursos exclusivos a instituições de ensino e seus membros.

Como membro desta organização, você tem acesso aos seguintes benefícios:

| Recurso | Descrição |
|---|---|
| **GitHub Copilot** | Assistente de IA para geração e complementação de código diretamente no seu editor |
| **GitHub Codespaces** | Ambiente de desenvolvimento completo na nuvem, sem necessidade de configuração local |
| **GitHub Actions** | Automação de fluxos de trabalho (CI/CD) sem limitações de minutos para repositórios públicos |
| **GitHub Packages** | Hospedagem de pacotes privados integrada ao repositório |
| **GitHub Pages** | Hospedagem gratuita de sites estáticos a partir de repositórios |
| **GitHub Classroom** | Ferramenta para criação e gerenciamento de atividades e avaliações práticas |
| **Ferramentas parceiras** | Acesso a ferramentas de desenvolvimento de parceiros do programa (IDEs, plataformas cloud, cursos, etc.) |

## 🎒 GitHub Student Developer Pack — Copilot Gratuito

Além dos recursos da organização, cada aluno pode solicitar individualmente o **[GitHub Student Developer Pack](https://education.github.com/pack)**.

Com o Student Pack você garante, entre outros benefícios, o uso **gratuito do GitHub Copilot** na sua conta pessoal.

### Como solicitar:

1. Acesse [education.github.com/pack](https://education.github.com/pack) e clique em **"Sign up for Student Developer Pack"**
2. Faça login com a sua conta GitHub
3. Informe que você é **estudante** e selecione sua instituição de ensino (SESI)
4. Envie um comprovante de matrícula ou e-mail institucional para verificação
5. Aguarde a aprovação (geralmente em até 24–48 horas)

> **Dica:** Após a aprovação, ative o Copilot em [github.com/settings/copilot](https://github.com/settings/copilot) e instale a extensão no VS Code ou na IDE de sua preferência.
